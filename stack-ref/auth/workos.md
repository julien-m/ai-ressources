# WorkOS

> _Auth enterprise B2B — SSO SAML, SCIM, Directory Sync._

## Ce que c'est
Plateforme d'auth orientée **enterprise B2B**. Spécialisé sur SSO SAML/OIDC, SCIM (provisioning automatique depuis Okta/Azure AD), et Directory Sync. La solution quand un client enterprise exige "on a besoin de SSO avec notre IdP".

## Free tier
- **1 million MAU gratuits** pour l'auth standard
- SSO : payant par connexion

## Features clés
- SSO SAML 2.0 / OIDC
- SCIM (provisioning/deprovisioning automatique)
- Directory Sync (Okta, Azure AD, Google Workspace)
- Audit logs
- Admin Portal pour les admins IT client (self-service)
## ✅ Quand utiliser
- SaaS B2B dont les clients enterprise exigent SSO
- Besoin de SCIM (provisioning automatique depuis l'IdP client)
- Audit logs pour compliance
## ❌ Quand ne PAS utiliser
- App grand public / B2C → Clerk ou Better Auth
- Early stage sans clients enterprise → overkill
- Budget limité → attendre que le besoin SSO arrive vraiment
