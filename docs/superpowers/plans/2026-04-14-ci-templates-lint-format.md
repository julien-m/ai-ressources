# CI Templates Lint/Format Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ajouter lint/format (diff-only sur fichiers modifiés) à tous les templates CI de conventions.init, avec typecheck/build/test en full codebase.

**Architecture:** Chaque template reçoit : concurrency, tj-actions/changed-files pour source + config (avec separator newline), logic if/elif/else en shell script (variables env pour lisibilité), caching des dépendances linter. Go utilise `golangci-lint --new-from-rev` natif. Rust et .NET en full (pas de per-file natif).

**Tech Stack:** GitHub Actions YAML, tj-actions/changed-files@v45, golangci/golangci-lint-action@v6, ruff, mypy/pyright, biome ci, eslint, prettier

**Refinements Codex appliqués:**
- `biome format --check` n'existe pas → remplacé par `biome ci`
- hashFiles syntax : deux arguments séparés
- Guards vide-fichiers via env vars + if/elif/else dans un seul step shell
- Go fallback : `git rev-list --max-parents=0 HEAD` (root commit, pas HEAD)
- Rust cache : suppression de `target/` (trop grand, causes cache eviction)
- dotnet format : `--no-restore` ajouté
- Logic conditionnelle : un seul step shell avec env vars plutôt que steps multiples avec `if:`
- Task 6 cc-hub : supprimée (templates non-SKILL.md, pas de sync requis)

```yaml
        with:
          fetch-depth: 0  # required for changed-files action

        with:
          python-version: "3.11"

      - name: Cache pip

          path: ~/.cache/pip

          restore-keys: pip-

        shell: bash
        run: |
          python -m pip install --upgrade pip
          pip install ruff
          if [ -f requirements.txt ]; then
            pip install -r requirements.txt
          elif [ -f pyproject.toml ]; then
            pip install .
          else
            echo "No supported Python dependency file found."
          fi

      - name: Get changed Python files
        id: changed-src
        uses: tj-actions/changed-files@v45
        with:
          separator: "\n"
          files: |
            **/*.py

      - name: Get changed linter config files
        id: changed-cfg
        uses: tj-actions/changed-files@v45
        with:
          files: |
            pyproject.toml
            ruff.toml
            .ruff.toml

      - name: Format check
        shell: bash
        env:
          CFG_CHANGED: ${{ steps.changed-cfg.outputs.any_changed }}
          SRC_FILES: ${{ steps.changed-src.outputs.all_changed_files }}
        run: |
          if [ "$CFG_CHANGED" = "true" ]; then
            ruff format --check .
          elif [ -n "$SRC_FILES" ]; then
            echo "$SRC_FILES" | xargs ruff format --check
          else
            echo "No Python changes, skipping format check."
          fi

      - name: Lint
        shell: bash
        env:
          CFG_CHANGED: ${{ steps.changed-cfg.outputs.any_changed }}
          SRC_FILES: ${{ steps.changed-src.outputs.all_changed_files }}
        run: |
          if [ "$CFG_CHANGED" = "true" ]; then
            ruff check .
          elif [ -n "$SRC_FILES" ]; then
            echo "$SRC_FILES" | xargs ruff check
          else
            echo "No Python changes, skipping lint."
          fi

      - name: Typecheck
        shell: bash
        run: |
          if grep -qE '^\[tool\.mypy' pyproject.toml 2>/dev/null || test -f mypy.ini || test -f .mypy.ini; then
            pip show mypy >/dev/null 2>&1 || pip install mypy -q
            mypy .
          elif grep -qE '^\[tool\.pyright' pyproject.toml 2>/dev/null || test -f pyrightconfig.json; then
            pip show pyright >/dev/null 2>&1 || pip install pyright -q
            pyright
          else
            echo "No type checker configured — skipping"
          fi

      - name: Run tests
        shell: bash
        run: |
          if command -v pytest >/dev/null 2>&1; then
            pytest
          else
            echo "pytest not installed, skipping tests."
          fi
```

```yaml
name: CI

on:

  pull_request:

concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true

jobs:
  ci:
    runs-on: ubuntu-latest

    permissions:
      contents: read

    steps:
      - name: Checkout
        uses: actions/checkout@v4
        with:
          fetch-depth: 0  # required for changed-files action

        uses: actions/setup-node@v4

          files: |
            **/*.ts
            **/*.tsx
            **/*.js
            **/*.jsx

      - name: Get changed linter config files
        id: changed-cfg
        uses: tj-actions/changed-files@v45
        with:
          files: |
            biome.json
            biome.jsonc
            .eslintrc
            .eslintrc.js
            .eslintrc.cjs
            .eslintrc.json
            .eslintrc.yaml
            .eslintrc.yml
            eslint.config.js
            eslint.config.mjs
            eslint.config.cjs
            tsconfig.json
            tsconfig.*.json
            .prettierrc
            .prettierrc.js
            .prettierrc.json
            .prettierrc.yaml
            .prettierrc.yml
            prettier.config.js

      - name: Format check

        env:
          CFG_CHANGED: ${{ steps.changed-cfg.outputs.any_changed }}
          SRC_FILES: ${{ steps.changed-src.outputs.all_changed_files }}
        run: |
          HAS_BIOME=$([ -f biome.json ] || [ -f biome.jsonc ] || grep -q '"biome"' package.json 2>/dev/null && echo true || echo false)
          HAS_PRETTIER=$([ -f .prettierrc ] || [ -f .prettierrc.js ] || [ -f .prettierrc.json ] || \

          if [ "$HAS_BIOME" = "true" ]; then
            if [ "$CFG_CHANGED" = "true" ]; then
              npx biome ci .
            elif [ -n "$SRC_FILES" ]; then
              echo "$SRC_FILES" | xargs npx biome ci
            else
              echo "No JS/TS changes, skipping format check."
            fi
          elif [ "$HAS_PRETTIER" = "true" ]; then

              npx prettier --check .
            elif [ -n "$SRC_FILES" ]; then
              echo "$SRC_FILES" | xargs npx prettier --check
            else
              echo "No JS/TS changes, skipping format check."
            fi
          else
            echo "No formatter configured — skipping format check"
          fi

      - name: Lint
        shell: bash
        env:
          CFG_CHANGED: ${{ steps.changed-cfg.outputs.any_changed }}
          SRC_FILES: ${{ steps.changed-src.outputs.all_changed_files }}
        run: |
          HAS_BIOME=$([ -f biome.json ] || [ -f biome.jsonc ] || grep -q '"biome"' package.json 2>/dev/null && echo true || echo false)
          HAS_ESLINT=$([ -f .eslintrc ] || [ -f .eslintrc.js ] || [ -f .eslintrc.cjs ] || \
                       [ -f .eslintrc.json ] || [ -f eslint.config.js ] || [ -f eslint.config.mjs ] || \
                       [ -f eslint.config.cjs ] && echo true || echo false)

            else
              echo "No JS/TS changes, skipping lint."
            fi
          else
            echo "No linter configured — skipping lint"
          fi
```

```yaml
# @generated by conventions.init — do not edit manually
# Generated by conventions.init — re-run to regenerate after upgrading ai-ressources.
# WARNING: action tags are unpinned. tj-actions/changed-files was compromised in a
# supply-chain attack (March 2025). Pin to SHA before using in production.
# golangci-lint uses --new-from-rev for diff-only lint (includes gofmt + go vet).
# Force-push is not supported for diff-only (golangci-lint compares against a fixed base rev).
# fetch-depth: 0 required for --new-from-rev — do not change.
name: CI

on:
  push:
  pull_request:

concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true

jobs:
  ci:
    runs-on: ubuntu-latest

    permissions:
      contents: read

    steps:
      - name: Checkout
        uses: actions/checkout@v4
        with:
          fetch-depth: 0  # required for golangci-lint --new-from-rev

      - name: Setup Go
        uses: actions/setup-go@v5
        with:
          go-version-file: go.mod  # go.mod must contain a 'go X.Y' directive

      - name: Compute base rev
        id: base-rev
        shell: bash
        run: |
          if [ "${{ github.event_name }}" = "pull_request" ]; then
            echo "rev=origin/${{ github.base_ref }}" >> $GITHUB_OUTPUT
          else
            # On push: compare against parent commit. Falls back to root commit on first push.
            REV=$(git rev-parse HEAD~1 2>/dev/null || git rev-list --max-parents=0 HEAD)
            echo "rev=$REV" >> $GITHUB_OUTPUT
          fi

      - name: Lint (golangci-lint, diff-only)
        uses: golangci/golangci-lint-action@v6
        with:
          args: --new-from-rev=${{ steps.base-rev.outputs.rev }}

      - name: Test
        run: go test ./...

      - name: Build
        run: go build ./...
```
