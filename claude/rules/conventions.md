# Conventions — Dispatcher

**These rules apply when the task involves creating, renaming, or organizing files in this project, OR when resolving conflicting conventions.**

Before acting, load the relevant convention file:

| Signal | File to load |
|--------|-------------|
| Creating, renaming, or deleting a file | **Read** [`naming.md`](../../conventions/naming.md) |
| Conflicting rules between general and language-specific conventions | **Read** [`authority.md`](../../conventions/authority.md) |
| Producing diagrams, flows, or acceptance criteria | **Read** [`diagrams.md`](../../conventions/diagrams.md) |

These files are in `conventions/` at the project root.
